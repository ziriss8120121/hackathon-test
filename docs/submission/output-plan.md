# 提出物アウトプット計画

## 1. 目的

仮説、分析指標、グラフ、提出物の対応関係を整理する。

この文書は、実装仕様やラベル定義を決めるものではない。ラベリングの要求は [`labeling-analysis-spec.md`](labeling-analysis-spec.md) を参照する。

## 2. 成果物の役割

| 成果物 | 役割 |
|---|---|
| `result.md` | 提出時点の最新20 Trialを対象にした分析結果の一次成果物 |
| 説明資料 | RQ1・RQ2の主要結果と代表Caseを説明する |
| デモ動画 | 1セット内の混合構成と同質構成の動作・結果比較を見せる |
| `README.md` | GitHubリポジトリ、資料、デモ、結果への入口 |

## 3. 分析単位

- 1セット（Trial）は17試合で構成される。
- 1セットには、混合構成1試合と、16種類のMBTIタイプによる同質構成16試合が含まれる。
- RQ1は、同じTrial内の混合構成と同質構成を比較する。
- RQ2は、同質構成の各MBTIタイプをTrial横断で比較する。
- 発言ラベルはSpeech単位で取得し、必要に応じてCase・Trialへ集約する。

## 4. 主要分析テーマ

### A. 正しく見抜けたか・勝敗

- `R1-02` / `R2-02`：人狼を見抜けたか
- `R1-03` / `R2-03`：村人陣営が勝ったか

### B. 収束・投票集中と正しさ

- `R1-04` / `R2-04`：意見の収束・分散
- `R1-05` / `R2-05`：投票の集中・分散
- `R1-08`：同質構成の収束の速さ・強さ
- `R1-10` / `R2-08`：収束と正しさの関係

### C. 判断を修正できたか

- `R1-06` / `R2-06`：判断変更
- `R1-07` / `R2-07`：確信度の変化
- `R1-09`：誤った初期判断の修正

発言ラベルによる主導・追随・疑いの伝播などは、A〜Cの結果を説明する補足分析として扱う。

## 5. RQ1の出力

### 5.1 人狼を見抜けたか・勝敗

比較対象：同じTrialの混合構成と同質構成の代表値。

- 投票前判断の正答
- 実際の投票の正答
- 村人陣営の勝敗

グラフ候補：段階別ドットグラフ、構成別ドットグラフ、分布比較。

### 5.2 意見の収束・分散

- 意見の収束・分散
- 収束の速さ
- 投票の集中・分散

グラフ候補：構成別の分布比較。必要に応じて、同質代表値−混合値の差分ドットを補助的に使う。

### 5.3 判断の修正

- 判断の維持
- 正しい方向への修正
- 誤った方向への変更
- 確信度の変化

グラフ候補：判断状態の100%積み上げ棒、確信度変化の分布比較。

### 5.4 収束と正しさ

収束度と正答をCase単位で比較する。

グラフ候補：収束度×正答の散布図。

## 6. RQ2の出力

同質構成の16タイプをTrial横断で探索比較する。タイプの優劣や性格傾向を断定しない。

### 6.1 タイプ別に人狼を見抜けたか

グラフ候補：タイプ別の横向きドットプロット。

### 6.2 タイプ別の意見の収束

グラフ候補：タイプ別の箱ひげ＋Trial点。

### 6.3 タイプ別の判断修正

グラフ候補：タイプ別の修正率ドットプロット。

### 6.4 タイプ別の収束と正しさ

`result.md`では表または必要に応じた散布図で確認する。資料での掲載は結果が明確な場合に限る。

## 8. デモ動画

対象Case：

- 混合構成：`t001/c00-mixed`
- 同質構成：`t001/c10-ESFP`

流れ：

1. 操作開始画面
2. 2つのチャット動画を同時再生
3. 各人の結果を表示
4. 2ケースの結果を比較

### 各人の結果

プレイヤーごとに、以下を簡易表示する。

- プレイヤーID
- 最終役職
- 投票前判断の正誤
- 実際の投票の正誤

正誤判定は最終役職を基準とする。最終役職が人狼のプレイヤーは、村人陣営の正答判定対象外とする。

### 2ケース比較

ラベリングなしで取得できる項目を表示する。

- 勝敗
- 人狼を見抜けた人数
- 投票が正しかった人数
- 投票集中度
- 判断変更人数

収束度、発言ラベル、重要発言タイムライン、主張と役職の突合は今回のデモには含めない。
