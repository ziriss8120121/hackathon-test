# docs

人狼テストの補足メモ置き場です。

詳しい仕様や意思決定はConfluenceに置き、ここには実行に近いメモだけを置きます。

## 置くもの

- ローカルで動かす時のメモ
- 実験条件の補足
- GitHub Pagesで見せる内容のメモ

## ファイル

| Path | 内容 |
| --- | --- |
| `requirements.md` | 要求定義書（Confluence正本のマークダウン版） |
| `system-requirements.md` | 要件定義書。システムが満たすべき要件と受入基準 |
| `design.md` | 設計書。構成、処理シーケンス、データ構造、実装順序 |
